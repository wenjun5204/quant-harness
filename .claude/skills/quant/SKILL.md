# /quant — 模拟盘当日值守汇报

执行以下步骤并汇总成一屏报告：

1. 运行 `./.venv/bin/quant-harness status`
2. 运行 `./.venv/bin/quant-harness report`（取最新日报）
3. 检查 `logs/daily.log` 的最后 20 行（`tail -20 logs/daily.log`），确认今天 cron 是否已跑、有无报错
4. 若 `status` 显示"最近处理"早于最近一个交易日，运行 `./.venv/bin/quant-harness daily` 补跑后再汇报

汇报格式（用户看得懂的中文，不要堆术语）：

- **一句话结论**：今天系统状态是什么（空仓等待 / 持仓中 / 需要你操作 / ⚠️ 异常）
- **关键数字**：净值、累计收益、当前回撤、趋势读数（附解释：>0 持有，≤0 空仓等待）
- **待办**：
  - 空仓等待 → 明确说"今天无需任何操作"
  - 明日待成交有订单 → 列出标的/方向/数量，说明"这是实盘手动跟单信号，次日开盘执行"
  - halted → ⛔ 熔断状态，向用户说明原因，询问是否 `--resume`（不要自动执行）
- **异常**：数据失败、订单取消等，解释原因和影响

注意：
- 如实汇报，模拟盘亏损就直说，不要粉饰
- 不要给实盘买卖建议——系统信号就是全部，信号的含义已在上面定义
- 不承诺盈利
